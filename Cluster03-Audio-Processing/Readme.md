

## Overview



- Images
- Audio files

The application automatically identifies the file type and runs the appropriate analyzer to generate a detailed metadata report.

## Features

- Offline metadata extraction
- Supports image, audio, and video analysis
- Automatic file type detection
- Extracts technical and metadata information
- Generates structured reports

### Images
- JPG / JPEG
- PNG
- BMP
- WEBP
- TIFF

### Audio
- MP3
- WAV
- OGG
- FLAC
- AAC

### Video
- MP4
- MKV
- AVI
- MOV
- WEBM
